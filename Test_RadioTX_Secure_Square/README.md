# 方板安全发送工程 V4 — 严格单对端

搭配 `Test_RadioRX_Square`，每块板仅保存一个当前对端。
完整协议、测试和边界说明见接收工程 README。

发送板 CODE 持续按住超过约 2 秒，即亮灯并开始对码；
不需要松手才触发，持续按住只触发一次。短按无效。
接收板也须先 CODE 长按进入对码；成功两闪后常亮，再长按退出。
普通 SWITCH/USER 按键触发一次数据，匹配 ACK 后绿灯亮 1 秒。

上电准备一次性临时密钥，第一次握手更快；重新对码会重新生成密钥。
普通断电保存当前接收端 ID 和独立链路密钥。
新的绑定成功后旧接收端不再是本机可接受的通信对象。
对码失败退出上限 30 秒。

Keil：`MDK\Test_RadioTX_Secure_Square.uvprojx`
HEX：`MDK\Build\Test_RadioTX_Secure_Square.hex`
构建：`.\build.ps1`

构建时需要在本地提供 `User/provision_secret.h` 中的安装密钥。请通过私下渠道获取和保管该文件及含有密钥的固件。
本原型安装密钥会编入固件，不能抵御掌握密钥者；
没有设置硬件读保护。安全版仍不保证射频信号不可采集。
不能和 V5 快速版混用。初次升级本严格单对端版本建议双方重新对码。
