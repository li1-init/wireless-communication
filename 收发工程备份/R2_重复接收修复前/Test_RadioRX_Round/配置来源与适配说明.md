# R2 无线配置来源

本次保留导入文件的原始注释与生成信息。它是 WDS 3.2.11 为 Si4464 B1 生成的 EZRadioPRO B1 API 调制器配置，**不是已经在本用户 Si4438 板上测试成功的成品参数表**。本工程基于观测到的 Si4438 芯片/API 修订信息进行兼容适配，需要新一轮两板实测确认射频效果。

来源仓库：PaulStoffregen/RadioHead。

固定提交：`0b1d577e8803ba197be1bcdc8aadfc7ea80c89d6`。

来源文件：`RF24configs/radio_config_Si4464_30_434_2GFSK_10_20.h`。

原文件 SHA-256：`990c8ae0f8dd130ba8b1e88a88986198d81d6aa9dfb1cdae94b3d8ee9a9e0cc4`。

原文件网络位置：

```text
https://raw.githubusercontent.com/PaulStoffregen/RadioHead/0b1d577e8803ba197be1bcdc8aadfc7ea80c89d6/RF24configs/radio_config_Si4464_30_434_2GFSK_10_20.h
```

导入后文件名为 `User/radio_config_b1_10k.h`。原文件内容未改；具体适配在 `User/radio_link.c` 中显式定义：

- 434 MHz 改为 433 MHz，保持 30 MHz 晶振、相同频段分频设置。
- 保留用户原板的 XO_TUNE=0x45。
- PA_PWR_LVL=0x10，PA_TC 使用 B1 表的 0x3D。
- 辅助 GPIO 置高阻，MCU 通过 SPI 轮询。
- 公共包字段改为 16 字节，加硬件与应用层 CRC16，明确关闭多余字段。
- 只接受当前已观测的 PART=0x4438、CHIPREV=0x11、ROMID=0x03。

旧 `radio_config_wds.h` 仅保留为回归测试输入，生产代码不再包含它。

参考资料名称：Silicon Labs AN633（命令与 CTS 流程）、AN625（旧版命令 API）、AN897（B1/C2 迁移差异）；项目中的 Silicon Labs 命令头文件；上述 WDS B1 生成表。
